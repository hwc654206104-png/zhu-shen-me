# 猪什么

**猪什么**是一款帮助用户决定“今天吃什么”的微信小程序。记录冰箱里的食材，选好口味和菜数，就能生成一份适合自己的一餐。

## 功能

- **我的冰箱**：添加、删除家里的食材，支持搜索食材及常见别称。
- **生成菜单**：选择人数、菜数、菜系、辣度和咸淡，优先利用冰箱里的食材。勾选“仅用冰箱食材”时，菜谱所需食材必须齐备；葱、姜、蒜按常备食材处理。
- **换一份**：保留喜欢的菜，只更换其余菜；同一轮中避免重复菜单组合。
- **盲盒**：随机发现菜谱，打开后可查看做法或收藏。
- **收藏与做菜**：按单道菜收藏，查看配料和步骤，记录做菜进度；一餐完成后可选择移除用过的冰箱食材。
- **好友**：通过邀请建立好友关系，查看好友分享的收藏菜谱和成就。

## 本地运行

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，导入本仓库目录。
2. 在开发者工具中配置**自己的小程序 AppID**。仓库中的原项目配置仅供参考。
3. 食材同步、好友和共享功能依赖微信云开发。如需使用，请创建自己的云开发环境，修改 `miniprogram/app.js` 中的环境 ID，并按自身环境配置数据库与部署 `cloudfunctions/` 下的云函数。
4. 编译后在模拟器或真机预览。请先在独立测试环境验证云函数权限和数据读写，勿将本仓库的配置或菜谱目录直接覆盖现有正式环境。

项目使用微信小程序原生页面，`miniprogram/` 为前端，`miniprogram/recipe-book/` 为菜谱分包，`cloudfunctions/` 为云函数，`scripts/` 和 `tests/` 分别存放构建脚本与测试。

## 菜谱与许可

公开副本的菜谱和食材索引已经重新构建。由于公开再分发范围尚未确认，**CookLikeHOC 原文及其 40 道菜谱未包含在本仓库**，因此公开版与原项目的菜谱数据不同。

其他第三方菜谱的许可文件位于 [`docs/miniapp/recipes/references/`](docs/miniapp/recipes/references/)。使用或再分发相关内容时，请遵循对应来源的许可及署名要求。本仓库暂未为项目整体指定开源许可证。

仓库保留运行所需的菜谱数据；部分采集脚本和测试依赖的上游原始资料未包含。菜谱数据经过程序检查，烹饪效果和食材用量仍需根据实际情况判断。
